Kết Nối Google Sheets 2 Chiều

Các bước kết nối nhanh:

  1. Mở file Google Sheets của chị Huyền.
  2. Vào menu Tiện ích mở rộng (Extensions) → Apps Script.
  3. Dán mã từ file Google_Sheets_Sync_Script.js vào và nhấn Triển khai (Deploy) → Tùy chọn triển khai mới.
  4. Chọn loại Web App, quyền truy cập để Bất kỳ ai (Anyone).
  5. Copy URL dán vào ô bên trên và bấm Lưu cấu hình.
